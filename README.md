# LIGENTEC Chip Layout for MPW 45 scheduled in OCT 2026
 This github repository is created to build the chip layout to evaluate the loss of the AN800 platform after their process change in 2026.

> 🚀 **IMPORTANT** 🚀
>
> Python version- 3.12.10
>
> gdsfactory version- 9.48.0
>
> PDK version- 8.9
>
>Install python 3.12.10 on your PC and then run setup.bat 
>The .bat file will create a virtual environment in your project directory and install the required python packages.
>Test that everything is set up well by running test.py
